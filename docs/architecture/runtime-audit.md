# Runtime completion audit

This audit maps runtime requirements to native source and tests. The latest local source pass ran all 33 native PostgreSQL tests and Clippy successfully, including effective notification availability and UTF-16 login bounds. CI at `f891347` passed the prior 32-test native suite, 28 unit tests, standalone HTTP/probe tests, release binaries, both Linux images and native container smoke checks; the final commit must obtain its own green run.

| Requirement                                               | Evidence                                                                                                                                                                                                                                                                                                                                                                               |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Token sessions, cookies, expiry, CSRF and rate limits     | `native_sessions_csrf_and_rate_limits` exercises login, secure/HttpOnly/SameSite cookie use, denied cross-origin logout and the sign-in limit. `backend/src/auth.rs` unit fixtures independently match existing Node HMAC session bytes, expiration and token equality.                                                                                                                |
| OIDC discovery, PKCE, callback, logout and safe redirects | `oidc_pkce_signed_tokens_callback_and_logout` uses an HTTP provider with signed tokens, verifies S256/redirect/state/nonce, callback sessions, invalid claims, key rotation and logout. Disabled/unavailable provider tests and `backend/src/oidc.rs` cookie/redirect unit fixtures cover fallback and compatibility.                                                                  |
| Scheduling, concurrency, retries and execution fencing    | `native_queue_executes_http_and_records_incident_lifecycle_atomically`, `check_jobs_fence_changes_recover_leases_and_bound_database_retries` and check lifecycle tests verify scheduling/deduplication, claim replacement, bounded attempts, configuration/epoch fencing, observation policy and atomic incident/alert changes.                                                        |
| Worker heartbeat, retention and shutdown                  | `native_worker_schedules_reports_health_retains_active_work_and_stops` runs native loops, observes scheduled execution, retained active state, removed expired history and heartbeat, then verifies bounded shutdown. `backend/src/main.rs` maps process signals to the same shutdown channel and drain.                                                                               |
| Existing pg-boss queue transition                         | `handoff_preserves_real_pg_boss_jobs_and_refuses_live_claims_atomically` seeds actual legacy partitioned jobs using the old pg-boss library and verifies transactional transfer, IDs/times/retry state, rerun safety and refusal of live claims. README requires stopping old writers before handoff.                                                                                  |
| Notification management and delivery                      | Channel revision/redaction tests, delivery lease/retry/order/fencing/diagnostic tests and `native_alerts_deliver_managed_webhooks_and_cancel_obsolete_reminders` cover the retained ledger. `backend/tests/webhook.rs` checks actual HTTP acknowledgement, identity and unsafe destinations. Browser outage/recovery evidence includes delivered opening/recovery events.              |
| Regional enrollment, rotation/revocation and scoping      | Location hashing/rotation tests and `probe_http_protocol_credentials_secrets_observations_and_epoch_fencing` exercise scoped HTTP routes, secrets, observations and invalid credentials. Regional-round tests cover leases, duplicates, sanitization, current epochs, deadlines and insufficient coverage.                                                                             |
| Standalone native probe replacement                       | `standalone_rust_probe_enrolls_executes_and_drains_sigterm_report` starts the Rust executable against the native API, executes with a managed secret and drains a pending report after SIGTERM. `backend/tests/probe_runner.rs` verifies identity persistence/retry and legacy identity-file compatibility. The production probe image contains the Rust binary, with no Node tooling. |

The runtime gates above do not require modifying a user's active service or handing off a live queue. Local tests and the verified Linux container run establish the replacement's behavior under their explicit scope. Live Handstamp credentials, physical remote devices and production deployment were not exercised and must not be claimed from this evidence.

The API/client source audit and appearance/persistence browser samples are recorded in their companion documents. Final-head CI and final delivery status are recorded on PR #2. Performance evidence covers build, API memory/latency and cold navigation bytes; whole-stack/concurrent estimates are not established.
