# Architecture records

These are historical engineering records from StillUp's migration from Next.js and Node to Vite and
Rust: audits, verification notes, benchmarks and measurement data captured at specific commits.
They are not user documentation and are not kept up to date. Commit hashes and CI run links refer to
the state at the time of writing (CI logs expire).

For how to run, configure and use StillUp, see the [README](../../README.md), the guides in
[`docs/`](..) and the in-app documentation at `/docs`.
